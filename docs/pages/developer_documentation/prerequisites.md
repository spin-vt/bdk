# Prerequisites

If you prefer deploying the BDK software locally, follow the steps below (we recommend using Windows Subsystem for Linux 2 (WSL2) if you are on a Windows system):

**Prerequisites**:
- Docker Desktop
    - Download: <a href="https://www.docker.com/products/docker-desktop/" target="_blank">docker.com/products/docker-desktop/</a>
    - WSL2 (Windows User): <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank">learn.microsoft.com/en-us/windows/wsl/install</a>
    - Guide for using WSL2 for Docker backend: <a href="https://docs.docker.com/desktop/wsl/" target="_blank">docs.docker.com/desktop/wsl/</a>
    - Authenticating with a GitHub Personal Access Token: <a href="https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry" target="_blank">docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry</a>
- PostgreSQL
    - Download: <a href="https://www.postgresql.org/download/" target="_blank">postgresql.org/download/</a>
    - Creating a user and setting a password: <a href="https://www.postgresql.org/docs/8.0/sql-createuser.html" target="_blank">https://www.postgresql.org/docs/8.0/sql-createuser.html</a>
- SSH Key
    - Create key: <a href="https://docs.github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account
" target="_blank">github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account</a>
- MapTiler
    - Create account & API key: <a href="https://docs.maptiler.com/cloud/api/authentication-key/" target="_blank">docs.maptiler.com/cloud/api/authentication-key/</a>

**NOTE**: If on Windows, you must have Docker Desktop installed, set up for WSL2, and running for the Local Environment Setup to work correctly.
