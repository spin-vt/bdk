### FCC BDC Filing
A biannual submission required by the Federal Communications Commission (FCC) from Internet Service Providers (ISPs) that details where broadband service is available. This data helps the FCC assess and improve internet coverage nationwide, ensuring transparency and aiding in the allocation of federal broadband funding.

### FCC BSL Fabric
The Broadband Serviceable Location (BSL) Fabric is a dataset maintained by the FCC that identifies all locations in the U.S. where fixed broadband internet could be installed.

### KML Network Data
Keyhole Markup Language (KML) Network Data is a geospatial file format used to display and share network infrastructure data—like fiber routes or coverage areas.
