# Filing Tool
{: .no_toc }

## Table of Contents
{: .no_toc .text-delta }

1. TOC
{:toc}

The Filing Tool serves as the BDK home page.

### Profile
Update information associated with your User Account and Organization, including:
- The email address associated with your account
- Information related to your organization
  - Organization Name
  - Brand Name
  - Provider ID

Brand Name & Provider ID will be included in the filing, so make sure they are accurate.

### Upload
Upload FCC BSL Fabric (CSV format) and Network Data files (KML format). For each file you upload, specify the following as necessary:
- Max Download Speed (Mbps)
- Max Upload Speed (Mbps)
- Technology Type
  - Copper Wire
  - Coaxial Cable / HFC
  - Optical Carrier / Fiber to the Premises
  - Geostationary Satellite
  - Non-Geostationary Satellite
  - Unlicensed Terrestrial Fixed Wireless
  - Licensed Terrestrial Fixed Wireless
  - Licensed-by-Rule Terrestrial Fixed Wireless
  - Other
- Network Type
  - Wired
  - Wireless
- Latency
  - <= 100 ms
  - \> 100 ms
- Category
  - Business
  - Residential
  - Both

### Search
Search for fabric locations. Selecting one will guide you to its position. _Search by State_ allows you to search by state name.

### Editing Tool
If we overestimate your coverage, you can make corrections by using the polygon drawing tool to mark locations as unserved. To finalize a polygon, click on any drawn point. Click the _Your Edits_ button to view and submit your edits. Click the _Exit Editing Tool_ button once you are done using the tool.

### Your Filings
Select the deadline you are filing for. You will see all associated Fabric files, Network Data files, and Manual Edits you made. You can toggle map visibility for locations associated with a Network Data file. There is also an option to locate Manual Edits on the map. You can select specific files using the checkboxes. There are options to delete all checked files, delete the entire filing, and regenerate the map.

### Export Filing
Allows you to download the filing for the current selected deadline. You can review all information associated with your Network Data files using the _Edit Network Files Information_ tool. After you verify that everything is correct, select the option to download your filing. You should receive an FCC compliant BDC Report in CSV format.
