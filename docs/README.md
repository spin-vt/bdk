The BDK Documentation website is created using the Cayman Jekyll theme for GitHub Pages (https://github.com/pages-themes/cayman). To alter the documentation content, edit the corresponding Markdown (.md) page as follows:
- If you want to edit the BDK Service Documentation page, edit `index.md`
- If you want to edit the Developer Documentation page, edit `developer-documentation.md`

The website uses Markdown to display text. A guide on how to use Markdown can be found here: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax

To edit the layout of the website, including changing the header, or adding additional HTML elements, navigate to `_layouts/default.html`. This HTML page controls the layout of the theme.

To add custom CSS styling, navigate to `assets/css/style.scss`. Add CSS tags as necessary.
